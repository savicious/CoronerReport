# Coroner Report

**A digital Coroner Initial Telephone Summary for Contra Costa County law enforcement.**

Coroner Report is an iOS application designed to simplify death investigation documentation for patrol officers. The app replaces traditional paper forms with a guided digital workflow, allowing officers to generate a completed **Contra Costa County Coroner Initial Telephone Summary** directly from their iPhone.

Enter case information, generate a PDF, and share the completed summary via text, email, AirPrint, or save it directly to your device.

**No cloud connection required. No more running out of paper forms.**

## Features

### Guided Case Documentation
- Step-by-step data entry for coroner reporting.
- Optional driver's license scanning to help populate identifying information.
- Organized fields for decedent information and investigative details.
- Save incomplete reports and return to them later.

### PDF Generation & Sharing
- Generate a formatted Coroner Initial Telephone Summary.
- Preview completed reports directly on your iPhone.
- Send reports via text message or email.
- Print using AirPrint.
- Save PDF copies locally.
- Read information directly from the completed form when contacting the coroner.

### Privacy & Offline Functionality
- No cloud connection required.
- Case information is stored locally on the device.
- No account or subscription required.
- Access saved reports without an internet connection.

Coroner Report is designed primarily for:

- Patrol officers

## How It Works

1. **Create a Case** — Start a new Coroner Initial Telephone Summary.
2. **Enter Information** — Complete the guided reporting sections, optionally using driver's license scanning.
3. **Save Your Progress** — Store an incomplete case locally and resume later.
4. **Generate a PDF** — Create a formatted summary using the information provided.
5. **Review or Submit** — Read directly from the form, share electronically, print, or save a copy.

## Requirements

- Compatible iPhone
- iOS (minimum supported version to be confirmed)

## Privacy & Data Handling

Coroner Report is designed to operate without cloud-based case storage.

Case information remains stored locally on the user's device. Reports are shared only when the user initiates an export or sharing action.

**Important:** Users are responsible for complying with their agency's policies regarding sensitive information, device security, records retention, and approved methods of transmitting investigative reports.
